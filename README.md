# WeTrace 使用文档

适用版本：0.1.0。本文根据当前项目代码整理，更新日期：2026-10-30。

WeTrace 是一个在电脑上读取本机微信聊天记录的桌面应用，支持浏览和搜索消息、查看聊天规律与群成员发言统计、向 AI 提问，以及生成 HTML 和 PNG 报告。应用始终以只读方式访问微信数据库。另有独立的定时发送任务入口，默认关闭；当前未附带实际发送适配器，仅可保存草稿，不能执行发送。

## 1. 使用前准备

### 运行环境

- 当前项目的打包配置面向 macOS，已有安装产物为 Apple Silicon（arm64）版本。仓库中也包含 macOS x64 数据库库文件，但不能据此视为已有完整验证的 Intel 安装包。
- 本机需要有微信 4.x 的账号数据。密钥捕获工具包含微信 4.1.13 专用适配，其他版本能否捕获取决于实际兼容情况。
- 浏览本地消息、聊天脉络和发言统计无需配置 AI 模型。
- AI 对话与报告生成需要可用的文本模型；分析图片还需要图片理解模型；处理语音需要先下载应用提供的离线模型。

### 安装应用

项目当前的 `dist/` 目录包含：

| 文件 | 用途 |
| --- | --- |
| `WeTrace-0.1.0-arm64.dmg` | macOS Apple Silicon 安装镜像 |
| `WeTrace-0.1.0-arm64.zip` | 压缩版应用 |

打开 DMG 后，将 WeTrace 拷贝到“应用程序”并启动；也可以解压 ZIP 后打开应用。安装包应来自你信任的构建来源。

## 2. 首次连接微信

首次启动时，按照连接页完成环境检查、密钥捕获和消息同步。已经保存有效密钥的账号通常无需重复捕获。

### 第一步：确认数据目录

应用默认查找以下目录中的本地账号：

```text
~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files
```

进入应用后，可以在“设置 → 数据库与账号 → 数据目录”点击“更改”，选择实际数据目录。项目支持发现 `xwechat_files` 下的 `wxid_…` 账号目录，也支持直接选择账号目录。

只会读取这台电脑已保存的数据，不会从手机或云端补全历史记录。

### 第二步：按页面提示检查 SIP

当前密钥捕获方案需要读取微信进程内存，因此会检查 macOS 系统完整性保护（SIP）。SIP 开启时，应用会提供恢复模式操作指引。

关闭 SIP 会降低系统保护，应在了解影响后自行决定。需要操作时，按应用内指引进入恢复模式，在终端运行 `csrutil disable`，重启后返回 WeTrace。应用中的长按电源键进入恢复模式步骤面向 Apple Silicon 设备。

获取并验证密钥后，可在恢复模式终端运行 `csrutil enable`，再重启以恢复保护。已保存的有效密钥可用于后续读取；将来如果需要重新捕获，仍需满足捕获环境要求。

### 第三步：捕获数据库密钥

1. 启动微信，并在微信中退出当前账号，使其停留在未登录的登录页面。
2. 在 WeTrace 中点击获取密钥，按提示完成管理员授权。
3. 等待 WeTrace 显示监听已就绪，再回到微信点击“登录”。
4. 等待捕获完成，应用会验证密钥能否解密本地数据库。

操作顺序很重要：先启动监听，再登录微信。如果微信已经登录，先退出账号后重试。

数据库密钥保存在本机安全存储。账号不同或密钥失效时，需要针对相应账号重新获取。

### 第四步：同步本地消息

密钥验证通过后，点击同步按钮，等待应用读取本地会话并进入主界面。后续可以在“设置 → 数据库与账号”点击“立即同步”。

首次连接后还会建立全部聊天记录索引。数据较多时，消息浏览和索引建立可能需要等待；可在“数据库与账号”或“缓存与索引”查看进度。

## 3. 浏览和搜索消息

点击左侧“消息”，选择会话即可浏览记录。

- **会话分组**：群聊、联系人、服务与公众号、全部；默认展示群聊。
- **搜索**：在左侧搜索框输入联系人、群聊名称或聊天关键词，同时查看本地索引中的消息结果。
- **更早消息**：向上滚动接近顶部时自动加载历史记录，并保持当前阅读位置。
- **跟随新消息**：停留在聊天底部时，新消息会自动将旧消息向上推；向上查看历史时保留阅读位置，滚回底部后恢复跟随。
- **刷新当前会话**：点击会话名称旁的刷新按钮，重新读取并回到最新消息。
- **状态检查**：点击左下角头像，查看当前账号、密钥状态、聊天刷新状态和最近刷新时间。

应用会监听本地记录变化，并每 20 秒检查刷新。全部历史索引单独维护，每半小时增量更新，历史正文每天核对；因此最近消息刷新与历史索引更新并非同一进度。

聊天文字中的常用微信表情（例如 `[微笑]`、`[捂脸]`、`[加油]`）会优先显示本地打包的微信表情图片；资源库未覆盖时使用通用 emoji 回退，悬停可查看原始名称。消息原文与搜索关键词仍保留方括号名称，未知表情保持文字显示，普通 Unicode emoji 继续按兼容字体展示。正文、引用、合并转发和监控记录支持这种展示。

表情包消息会解析其标识和描述，尝试从当前账号本地表情目录（包括微信 4.x 的 `cache/YYYY-MM/Emoticon/MD5前两位/MD5`）读取可识别的 GIF、PNG、JPEG、WebP 等文件，GIF 保留原文件供界面播放。未下载、目录未适配或格式不支持时显示提示，可先在微信中打开后刷新。本地文件缺失时，显示消息会使用其中的微信 CDN 地址下载；只有 MD5 时，尝试通过本地 `emoticon.db` 查询下载地址。下载成功后按账号缓存在本机，后续优先使用缓存，不会将聊天文字发送给 AI。链接过期、查询不到地址、加密或格式不支持时显示具体原因，支持“重新加载”。不能保证所有微信版本的目录和专用格式都能解析。

“本地记录总数”与“已展示条数”含义不同：前者是本地可统计的会话记录，后者是当前已加载到聊天界面的消息，不相等通常是正常的。

| 快捷键 | 功能 |
| --- | --- |
| `⌘K` | 聚焦消息搜索 |
| `⌘,` | 打开设置 |

## 4. 聊天脉络与发言分析

### 聊天脉络

打开会话后，点击顶部“聊天分析”，在“聊天脉络”标签页查看。

1. 选择整个会话或某个成员。
2. 默认查看今天，可通过日期范围选择器自定义日期，或切换今天、近 90、180、365 天。
3. 查看每日消息量、活跃天数和规律变化提示。
4. 点击日期柱形或“查看当天聊天”，回看当天原文。

此功能基于本地记录和本机时区进行统计，不需要 AI 模型。明显变化的判断需要足够的历史参考，缺失的本地记录也可能表现为沉默；统计结果不能解释个人动机。

### 群聊发言分析

在群聊顶部点击“聊天分析”，切换到“发言分析”标签页，选择全部时间、今天、近 7 天、近 30 天或自定义日期。

可以查看发言总数、发言人数、成员排行与占比，并通过“复制统计”复制结果。系统通知不计入发言。

“未发言成员”依赖当前群成员名单。名单读取失败时会提示不可用，不能将其理解为没有未发言成员；当前成员名单也不等于历史任意时刻的成员名单。

表情展示参考了 [TraceMemo 的文字表情实现](https://github.com/Wxw-Gu/TraceMemo/blob/d6d837e6f6705741000b747af99d75ab120281bd/src/renderer/src/utils/wechatEmojiText.tsx) 和 [表情包缓存目录读取](https://github.com/Wxw-Gu/TraceMemo/blob/d6d837e6f6705741000b747af99d75ab120281bd/src/main/sticker-service.ts)。WeTrace 也提供 CDN 下载缓存与 `emoticon.db` 地址查询回退，读取和下载放在后台，通过应用内媒体地址显示。

### 撤回消息显示

数据库或 WAL 变化时立即读取，并在变化暂歇约 150 毫秒后复查；读取期间的新变化会在当前任务结束后继续处理。正常同步聊天记录时，会自动加密保留已读取到的消息基线，不需要开启群聊监控。通过原记录 ID 或撤回通知中的目标消息 ID 精确关联后，原文在对应会话显示为“已撤回 · 已保留原文”。撤回通知更换了本地和服务端 ID 时，支持比较两次相隔不超过 2 分钟的实时记录：只有在有效读取范围内唯一一条已捕获消息消失、唯一一条撤回通知新增，且撤回者一致时才关联；滚出分页范围、多个候选或不稳定 ID 都不自动关联。仅有撤回时间的通知不能凭时间猜测关联；如果原消息所在记录被替换但其 ID 没有变化，可通过该 ID 恢复已捕获原文。无法关联时显示可读的撤回提示，并区分没有捕获原文与已有会话缓存但无法确定对应原文，不显示原始 XML。

自动捕获范围为每次同步实际读到的会话消息（当前最多 120 个会话、各最近 60 条），每个会话最多保留 5000 条基线；未读到的消息、撤回前未完成同步的消息和超出保留范围的原文无法恢复。被排除本地缓存的会话不会捕获。监控页面不提供清空或删除记录操作。

### 群聊监控

点击左侧“监控 → 新建事件”，选择一个或多个群聊，选择聊天消息、成员离群、成员加入中的一种事件类型，点击“创建并开启”。同一群聊再次创建会更新该群的事件类型配置。也可搜索并选择群聊后点击“开启此群监控”。可重置筛选，按页查看事件；可同时监控多个群，按群聊、事件类型和关键词查看记录。

- **聊天消息**：记录开启监控后读取到的新消息，支持关键词搜索。
- **成员变化**：比较两次成功读取的成员名单，记录加入及离群；时间为发现时间，不能区分主动退群与被移出。首次读取只建立基线，名单失败会显示错误，不会记录为退群。
- **消息撤回**：保留已捕获的文字原文，通过消息标识或原记录被替换来关联撤回通知；已关联的原文仅在“消息”里的对应聊天记录展示，标注“已撤回 · 已保留原文”，监控页面不展示撤回事件及对应已撤回消息。无法关联时，聊天记录保留原本的撤回通知。不会阻止微信客户端撤回。未读取到的内容不能恢复；已读取的图片、视频会另存加密媒体文件，撤回后可查看图片或播放视频。

应用运行且已连接账号时，每 5 秒检查本地数据库，数据库变化也会触发检查。切换到其他页面后监控继续；退出应用后停止，重新打开会继续已开启的监控。首次读取最近 200 条消息建立基线，后续单次最多补读 10000 条，超过时显示缺口提示。关闭应用期间、检查间隔内及本地数据未保存时都可能漏记；成员名单读取可能有约 15 秒缓存。

监控记录按账号分开加密保存在本机，不发送给 AI。每群保留最近捕获的 5000 条消息基线，每账号保留最近 2000 条事件，界面每页显示 20 条匹配事件，可分页查看全部保留事件。暂停监控会保留记录，再开启时重新建立成员基线。被排除本地缓存的群不会继续采集，需先取消排除。

## 5. 配置 AI 模型

进入“设置 → 模型配置”，保存文本或图片模型。可分别保存多份配置，并在使用时选择。

### 配置字段

| 字段 | 填写方式 |
| --- | --- |
| 配置名称 | 便于识别，例如“日常总结模型” |
| 模型模板 | DeepSeek、通义千问、Ollama（本地）或自定义；选择后会自动填写对应的地址与模型 ID |
| 接口格式 | 选择服务所支持的 OpenAI 或 Anthropic 兼容格式 |
| Base URL | 填写服务基础地址，不要附加 `/chat/completions` 或 `/messages` |
| 模型 ID | 填写服务提供的准确模型标识；图片配置需要支持图片输入的模型 |
| API Key | 填写相应服务的密钥，加密保存在本机 |

当前代码内置的默认文本模板如下。这些是应用预填值，实际可用性以服务端配置和连接测试结果为准。

| 模板 | 接口格式 | Base URL | 模型 ID |
| --- | --- | --- | --- |
| DeepSeek | OpenAI | `https://api.deepseek.com` | `deepseek-chat` |
| 通义千问 | OpenAI | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Ollama（本地） | OpenAI | `http://localhost:11434/v1` | 手动填写本机可用模型 ID |

保存后，在“已配置模型”中编辑配置、测试连接或管理默认模型。编辑已有配置时，API Key 留空会保留原密钥。切换模板会重新填充地址与模型 ID，保存前请检查。

图片模型需要单独配置，文本模型能连接成功并不代表具备图片理解能力。当前语音功能使用固定离线模型，不通过此页面配置在线语音服务。

## 6. 向 AI 提问

有两种入口：

- 在会话顶部点击“问 AI”，带入当前会话背景。
- 点击左侧“AI 对话”，在问题中写明群聊或联系人、人物与时间范围。

示例问题：

```text
总结“产品讨论群”最近 7 天讨论的重点。
最近 3 天，小明在这个群里主要聊了什么？
整理这个会话中关于上线时间的讨论，并给出原文依据。
```

在输入框下方选择文本模型，输入问题后按 Enter 发送，Shift + Enter 换行。生成过程中可以点击停止；历史对话支持重新打开、重命名和删除。“AI 对话设置”可以调整对话风格和提示词。

同一个 AI 对话会持续共享记忆，不再因达到40条消息要求新建。不同 AI 对话可以同时生成回答，每个对话分别维护进度、流式内容、记忆和取消状态；同一对话生成期间不能重复发送。

模型会按问题查询相关本地记录并整理回答。回答可能存在遗漏或误解，需要准确引用时请回看原文。

## 7. 生成聊天报告

### 按会话和日期生成

1. 点击“总结 → 生成报告”，或点击消息窗口右上角的“生成报告”直接选中当前会话。
2. 在左侧选择群聊或联系人。
3. 选择今天、昨天、近 7 天或自定义日期范围。
4. 勾选需要处理的内容类型，等待本地记录加载完成并确认条数。
5. 选择基础语言模型；勾选图片时，还必须手动选择图片理解模型。
6. 如果是群聊，可选择总结整个群聊或某个成员。个人总结会结合所选范围内的群聊上下文。
7. 选择内容风格，可新增并保存自定义风格；模板决定视觉排版，风格决定内容表达。
8. 选择手机端或电脑端版式，点击“生成报告”。

报告按所选日期范围读取记录，切换今天、昨天或自定义日期后重新加载对应范围；内容类型、模型和样式调整不重复取数。优先读取本地索引；索引尚未完成、过期、未命中或暂时不可用时，会直接读取原始聊天记录，无需等待索引完成。历史较多时加载会更久；读取超时或失败后可点击“重新读取记录”重试。排除索引的群聊也可直接读取原始记录生成报告。

| 内容类型 | 处理方式与前提 |
| --- | --- |
| 消息 | 纳入文字、链接、引用及其他消息内容 |
| 语音 | 在本机离线转写，将转写文本交给语言模型；需先下载离线模型 |
| 图片 | 发送至选定的图片理解模型；需配置并选择图片模型 |
| 视频 | 仅纳入统计，不解析视频内容 |

内容类型初始包含语音和图片。如果只需要文字报告，先取消勾选语音、图片和视频，即可减少准备步骤与处理量。

图片解析线程数默认是 3，可设置为 1–16 的整数。服务出现限流时可调低。已成功保存的图片理解和语音转写结果会在后续重试时复用。

### 只总结选中的消息

1. 打开“消息”中的目标会话。
2. 点击“选择消息生成报告”，勾选需要的消息。
3. 点击底部“生成所选消息报告”。
4. 在报告配置中确认所选范围，选择模型、风格与版式后生成。

此模式只总结所选消息，不自动添加其他消息或上下文。可以“返回调整选择”，也可以“改为按会话总结”。合并转发内容使用内部发言人进行处理。

### 查看进度与结果

右侧任务面板展示读取记录、离线语音识别、图片理解、模型分析以及保存文件的进度。任务提交后使用提交时的配置；生成期间继续调整页面配置不会更改当前任务。

报告默认同时输出 HTML 和 PNG。完成后可点击“复制图片”将报告图片复制到剪贴板，多张图片会按顺序合并为一张长图；也可点击“打开所在文件夹”获取文件。

保存位置为系统“文稿”目录下的：

```text
WeTrace Reports/
```

回到“总结”首页，可以在“已生成报告”搜索会话或统计日期，并重新打开历史报告。历史列表重启后仍可查看。“报告模板 → 查看示例”展示的是模拟数据，不是你的聊天记录。

失败时查看任务面板中的错误、建议和素材处理说明；如果界面提供诊断文件路径，可据此定位问题。重新生成前先排除模型连接、日期范围和素材准备问题。

## 8. 图片、语音与本地索引

### 图片解密

当前图片解密在读取消息时自动启用，仅在本机处理。图片密钥与数据库密钥相互独立，应用会尝试从微信本地缓存中自动识别，不需要手动填写。

消息中的图片支持点击查看大图，可缩放、旋转，按 Esc 关闭。点击时会重新查找本机图片；只能读取缩略图时会在预览中提示。优先展示本机可读取的原图；若微信仅缓存了缩略图或原图格式不支持，则展示可用的缩略图。

如果图片尚未下载，请先在微信中打开原图，再返回 WeTrace 刷新。解密图片的展示与将图片交给 AI 分析是两件事：生成报告并勾选图片后，才会使用所选图片理解模型处理。

### 离线语音转文字

进入“设置 → 语音转文字”，点击“下载模型”，等待 SenseVoice Small INT8 下载及校验完成，状态就绪后再生成包含语音的报告。

- 下载模型不会自动批量转写聊天语音。
- 报告处理时，语音在本机识别，成功转写结果写入本地缓存。
- 当前不支持通过设置切换在线语音服务或自定义语音模型。
- 可查看下载目录、进度与错误信息，也可删除模型文件。删除后如需处理语音，需重新下载。

该设置页目前存在“识别引擎：待接入”的静态说明，但报告流程已调用本地离线识别；请结合模型就绪状态和实际转写结果判断能否使用。

### 索引和缓存

在“设置 → 数据库与账号”或“缓存与索引”查看“全部聊天记录索引”。可暂停建立、继续建立或更新索引，暂停或退出后从已保存的批次继续，索引正文加密保存在本机。

群聊排除名单先保存生效，已有索引在后台清理；正在建立索引时也可排除，当前读取批次结束后停止收录该群。更新时会显示检查历史、处理消息或保存索引的当前阶段。

“缓存与索引”同时展示语音转写条数、图片理解数量及其占用，以及本地缓存总大小。生成报告后可以点击“刷新统计”。不同模型或版本可能分别缓存，因此缓存数量不等于聊天素材总数。

当前“缓存目录更改”“清理图片缓存”“清空数据”等按钮仍为提示占位，不能用于实际迁移或删除本地数据。“索引管理”按钮会提示使用上方“更新索引”。

## 9. 账号切换与数据范围

在“设置 → 数据库与账号 → 切换账号”选择本机已发现的账号。如果目标账号没有有效密钥，需要先完成该账号的密钥捕获与同步。

“退出 WeTrace”用于退出当前应用的账号视图，不代表退出微信，也不能视为删除本地密钥、缓存或报告。

数据处理范围如下：

| 操作 | 数据去向 |
| --- | --- |
| 消息浏览、搜索、聊天脉络、发言统计 | 本机读取和计算 |
| 数据库密钥、模型 API Key | 本机安全存储或加密保存 |
| 离线语音识别 | 音频在本机识别，转写结果本机缓存 |
| AI 对话 | 问题、对话上下文及查询到的相关内容发送至所选模型服务 |
| 报告生成 | 所选范围内的文本、语音转写及分析所需内容交给语言模型；图片交给所选图片理解模型 |
| HTML、PNG 报告 | 保存到本机文稿目录，文件可能包含聊天内容 |

使用远程模型时，相应内容会离开本机；使用本地兼容服务时，去向取决于你配置的服务地址。分享报告前请检查其中的个人信息和聊天原文。

## 10. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 未找到微信数据或账号 | 确认本机微信已产生账号数据，检查数据目录，必要时在设置中更改 |
| 提示 SIP 已开启 | 根据应用指引和本文首次连接部分检查密钥捕获环境 |
| 未找到微信主进程 | 启动微信并停留在未登录页面，再开始捕获 |
| 捕获超时或没有有效密钥 | 先退出微信账号；先等监听就绪，再登录；仍失败时检查微信版本适配和管理员授权 |
| 已保存密钥无法解密 | 确认选中了正确账号，并重新获取对应账号密钥 |
| 最近消息未出现 | 刷新当前会话，或在数据库与账号中立即同步；查看左下角账号状态中的刷新错误 |
| 搜索或报告缺少历史记录 | 检查索引进度并更新索引；确认这些记录本来就保存在这台电脑上 |
| 图片无法显示 | 先在微信中打开原图使其下载，再回到应用刷新；重新获取数据库密钥不等于修复图片密钥 |
| 报告提示缺少图片模型 | 配置并选择图片理解模型，或取消勾选图片 |
| 报告提示需要离线语音模型 | 先下载模型并等待就绪，或取消勾选语音 |
| 当前筛选没有记录 | 检查会话、日期、内容类型和手动选择范围，等待索引或记录加载完成 |
| 模型连接失败 | 核对接口格式、Base URL、模型 ID、API Key 和服务可用性；Base URL 不要填写完整请求端点 |
| 图片解析限流或失败 | 调低图片解析线程数，检查图片模型能力与服务限制，再重试 |
| 首次打开或建立索引较慢 | 观察索引进度；可以暂停索引后继续，避免反复重新初始化 |

## 11. 从源码运行（开发者）

项目使用 Electron、React、TypeScript 和 pnpm。运行前安装 Node.js 与 pnpm。项目未声明固定的 Node.js 最低版本，请使用满足当前依赖要求的版本；部分测试使用 `--experimental-strip-types`，需要支持该选项的 Node.js。

在项目根目录执行：

```bash
pnpm install
pnpm dev
```

构建、预览和打包：

```bash
pnpm build
pnpm start
pnpm package
```

`pnpm start` 预览已经构建的产物，需先执行构建；`pnpm package` 会先构建，再按 `electron-builder.yml` 生成 macOS DMG 和 ZIP 到 `dist/`。原生库及密钥工具来自 `resources/`，应完整保留。源码运行仍需满足前述微信数据与密钥要求。

常用检查命令：

| 命令 | 用途 |
| --- | --- |
| `pnpm typecheck` | TypeScript 类型检查 |
| `pnpm test:local` | 本地自检 |
| `pnpm test:startup` | 启动环境相关检查 |
| `pnpm test:index` | 索引相关检查 |
| `pnpm test:patterns` | 聊天脉络逻辑检查 |
| `pnpm test:analysis` | 聊天脉络逻辑及聊天分析标签页界面测试，包含构建 |
| `pnpm test:report` | 报告相关检查 |

部分检查会启动 Electron，或依赖本地环境、数据与模型配置。本文根据源码核对功能与操作流程，未将所有平台、微信版本及模型服务视为已经实测通过。

AI 问答的时间范围按问题确定，连续追问沿用已确认的范围；没有时间限制且无法沿用时使用全部本地聊天历史，不默认近一周。处理时间随记录数量和模型响应速度变化，可在问题中指定时间范围以减少等待。

AI 对话中，将鼠标移到自己发送的消息上可查看发送时间并复制原文；旧消息未保存时间时显示“发送时间未记录”。

人物分析默认给出连贯的整体人物描述，不罗列日期和聊天原话；追问判断依据、例子或原话时，再展开对应证据。

人物分析会先分批提取有区分度的人物特点及情绪事件，去掉寒暄、重复和无关信息；保留事件的触发原因、情绪表达、行动、他人回应、结果及必要原话，也保留稳定的日常表现与反例。提取后估算 token，并为提示词和回答预留空间；证据仍超预算时继续分层压缩，放得下则直接生成画像。token 为保守估算，并非模型专用的精确计数。

聊天记录较多时，AI 会分批读取所选范围内的记录，再按时间和场景分层合并证据，保留人物互动、差异与反例；不会因为容量不足自动缩短查询日期。每次请求会为提示词、近期问答背景和回答预留空间，模型明确提示上下文过长时自动缩小批次重试。超长的单条消息会拆分，并在各片段保留发言人和时间。人物证据可在本次应用会话内复用，连续追问不必重复分析相同批次；历史问答通过记忆摘要与近期完整问答共同保留，旧回答不作为微信原文事实依据。分层摘要仍可能遗漏细节，不能替代精确的全量频次统计。记录越多处理时间和模型调用次数通常越多，生成中可随时停止；多次缩小后仍不满足模型容量时会给出提示。

人物分析识别出明显情绪变化时，会根据目标本人的原话定位事件，回查该消息前后各40条原始记录（不超出查询日期范围），补充话题与触发原因；相邻回查范围会合并。无法从原文确认原因时会保留“原因不明”，不把时间相邻当成因果。回查证据也会参与后续压缩。

聊天列表中的语音消息可点击“转文字”，使用设置中已下载的 SenseVoice 离线模型在本机识别，结果直接显示在该消息下方。成功转写会按现有缓存策略复用；无需上传语音。模型未安装时请先到“设置 → 语音转文字”下载，本地语音数据缺失时需先在微信中下载。

AI 证据达到可用上下文预算的80%时会自动压缩，为后续回答预留空间。模型摘要超过目标字数不会直接失败，而会继续分批压缩；只要容量占用持续下降就继续处理，不限制为固定轮数。压缩未缩短时保留原证据并缩小批次重试，连续3轮仍无法压缩才停止，避免无限调用与丢失证据；界面显示轮次、批次和估算 token，压缩期间可停止。

AI 分批证据提取最多同时运行4个模型任务，每个任务处理一段记录，结果按原批次顺序汇总，再统一压缩和生成回答。分批阶段可并行提速，实际速度取决于模型服务的并发能力和限流；情绪回查与最终汇总仍按现有流程执行。

AI 人物分析即使未找到目标发言或所选日期没有记录，也会保留本次会话、目标人物和分析类型；继续说“最近七天呢，看一下”时只调整日期，沿用人物任务。最近N天包含今天，已有对话重新打开后也会复用已保存的查询条件。

同一 AI 对话的历史问答接近记忆预算阈值时，会将较早问答连同已有记忆合并为摘要，保留人物与代词关系、用户纠正、称呼约定、目标、关键结论及不确定性、未完成任务；近期问答在预算允许时保留完整原文。摘要随该对话保存在本机，重新打开后继续复用；不同对话不共享摘要。原始可见历史不会因压缩删除。旧对话首次继续时也会从原历史建立记忆。压缩仍可能损失细节，旧助手结论不会作为微信原文证据。

AI 对话历史、查询条件、关联会话和记忆摘要由主进程保存到固定的本地文件目录：macOS 为 `~/Library/Application Support/WeTrace/ai-conversations/`，不在安装包、页面 localStorage 或可清理缓存中。不同微信账号分别保存，正常覆盖安装 DMG 和清空页面存储不会删除这些文件。首次使用会自动迁移当前页面存储中仍可读取的旧对话；迁移前已经丢失的历史无法凭空恢复。保存采用原子替换并保留上一版 `.bak` 备份；文件损坏时尝试备份，无法恢复时会提示并保留原文件，避免空历史覆盖。卸载工具若连同应用数据目录一起删除，仍会删除本地对话，需自行备份该目录。

群监控状态保存使用独立临时文件，避免多个进程写入同一个临时文件时出现重命名失败。监控与撤回原文缓存暂时不可用时，会在消息页提示，但不阻止已读取的聊天记录展示；保留已有监控文件，不清空原始数据。

一个 AI 对话生成中仍可新建对话并发送问题，也可从消息页关联其他会话提问。切换对话不会中断原任务，停止按钮只停止当前对话；各对话的回答、错误与记忆分别保存。

### AI 长期记忆

AI 对话侧栏的「长期记忆」可保存回答偏好与称呼约定。记忆按当前微信账号隔离，重启或新建 AI 对话后仍可使用；支持删除单条、清空和关闭。关闭后保留已存内容但不再提供给后续模型请求。删除或关闭不会撤销已发出的请求，也不会改写历史回答。记忆由用户明确填写，人物分析结论不会自动保存；人物判断和原话引用仍须依据聊天记录。

### 人物分析与原文回查

在 AI 对话侧栏点击「人物分析」，选择会话和时间范围；私聊默认分析对方，群聊须选择具体成员。同名成员会分别列出，切换会话或日期后需要重新选择成员。开始分析会新建独立 AI 对话，可继续追问判断依据、例子或近期表现。

回答旁的「查看原话」按当次保存的会话和日期读取真实记录，可搜索发言人或原话并分页查看；人物分析中会区分本人发言和互动上下文。该窗口展示当次查询范围内的原始材料，不表示窗口内每条消息都被用作某个结论的依据。记录已不可读取时会显示错误，不把模型回答当成原文。

### 日报风格

日报新增「毒舌」「阴阳怪气」预设，生成前在风格中选择。两种预设只用于最终表达，中间证据保持客观；消息数、参与人数和原文仍来自真实记录。HTML 和 PNG 沿用同一份生成内容。报告历史保存并展示生成时的风格名称，自定义风格后来修改或删除也不会改写已生成的历史报告。

### P0 回归与平台边界

`pnpm test:p0` 执行类型检查、构建，以及长期记忆、人物分析、原文分页、自定义 AI 风格、日报风格和相关界面的模拟回归，不读取真实微信记录，不调用远程模型。长期记忆在模型容量允许的范围内选取，不保证每次携带全部条目；真实模型的表达差异仍需单独验收。

Windows 连接尚未开放。当前仓库缺少已验证的 Windows WCDB x64 DLL、密钥获取工具及微信 4.x 基线；应用会显示具体的不支持提示，避免进入 macOS SIP 指引。Windows 真机验证暂缓，不声明 Windows 已支持或已通过安装、同步与报告全链路验收。

### 定时发送与版本适配

「定时发送」可选择接收方、内容和未来时间，先保存待确认草稿。独立开关默认关闭；只有已安装且匹配微信完整版本的发送通道可开启功能，用户逐条确认后才进入执行队列。支持暂停、继续、取消和查看日志。错过执行时间超过5分钟的任务会暂停，不会在重启后静默补发。已开始发送的任务不能撤回；通道异常或应用在发送中退出会标记结果未知，不自动重试，请在微信核实。切换账号后不执行上一账号的待发送任务。任务内容使用系统安全存储加密保存在本机。

**当前尚未附带微信发送执行器，不声明真实消息已可发送。** 未适配平台或版本不能开启或确认发送，仅允许保存草稿。完整资源协议和版本矩阵见 [原生平台适配说明](docs/native-platforms.md)。

防撤回只保留已捕获的本地内容。增量同步补读上次捕获时间附近的记录，单次最多5000条，并只向消息页返回最近60条。超出捕获窗口或保留范围会显示对应状态。只通过原记录标识或唯一稳定服务端标识关联，不再凭“刚好少了一条消息”推测归属。已成功读取的图片、视频会按账号和会话保存独立的 AES-GCM 加密副本，撤回后可查看图片、播放视频并拖动进度。图片沿用现有解密流程；视频先通过微信 hardlink 映射表解析实际文件名，再查找本机附件目录中的完整 MP4；也支持原视频哈希及短视频消息（单个最多256MiB）。媒体副本去重保存，不受旧版1MiB图片快照及16/64MiB内嵌媒体限制；后续读取失败不会覆盖成功副本。副本占用本机磁盘空间，排除会话缓存时会删除该会话副本。应用当前没有调用微信服务器主动下载附件的接口；未下载到本机、撤回前未读取成功或不支持的媒体不能恢复。旧缓存中的内嵌图片和语音仍适用原来的容量限制。

`pnpm test:p1` 使用虚构记录和模拟发送通道，验证版本/资源校验、调度、捕获窗口、媒体关联和界面；不会发送真实消息。`pnpm package:windows` 需先提供清单和匹配的Windows原生文件，资源不足时明确失败，不生成伪可用安装包。Windows真机验收按当前要求暂缓。
