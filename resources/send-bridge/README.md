# 定时发送通道

发送通道与 WCDB 只读数据链路分离。本仓库尚未附带可执行的微信发送适配器；缺少适配器时，应用仅允许保存草稿，禁止开启和确认发送。

发布目录为 `<platform>/<arch>/sender`（Windows 为 `sender.exe`）及 `compatibility.json`：

```json
{"protocol":1,"versions":["明确的微信完整版本号"],"sha256":"适配器二进制的SHA-256"}
```

适配器由应用以 `send --json` 启动，从标准输入接收单个 JSON：

```json
{"protocol":1,"accountRoot":"账号目录","taskId":"幂等任务标识","recipientId":"准确会话标识","content":"经用户确认的内容"}
```

适配器必须先校验当前登录账号及接收方的稳定标识，不能只按昵称搜索后发送。必须按 taskId 做持久化幂等处理，不能把写入输入框或模拟按键当作成功送达。确认发送结果后，标准输出仅返回 JSON：

```json
{"taskId":"原任务标识","recipientId":"原接收方标识","receipt":"实际发送结果的可核验凭据"}
```

无法确认时以非零状态退出；应用将标记“结果未知”，不会自动重试。进程退出、超时、失去账号或版本不符时均应停止，不能退回昵称匹配或其他账号。禁止将数据库密钥、API Key、聊天内容写入标准错误或日志。适配器实现及各版本真机验收仍需补齐；清单不是验证证明。
